# Hand-drawn sprite art for the C64. A ":" line names a sprite, then its rows.
#
#   .           transparent
#   0-9 A-F     CPC pen number - the same pens as the CPC's assets/sprites.txt
#
# These are the CPC drawings with rows taken out: a C64 sprite is 21 lines, so
# the cat is 20 tall rather than 24 (loukc64.md 4.3), curled up 14 rather
# than 16 and flat 10 rather than 12. A multicolour pixel is 2:1 like a mode 0
# pixel, so nothing else had to change shape.
#
# tools/mksprite64.py turns this, and the PNGs in assets/art/sprite, into
# src/sprites.s. A name followed by "flip" also gets a mirrored copy.
# A name followed by "pickup" is not a hardware sprite at all: it is drawn
# into the bitmap, see src/art.s. Its highlight is pen 2, the shelves' own
# yellow, so a pickup on a shelf costs the cell only the two colours it
# brings: three is all a multicolour cell has.
